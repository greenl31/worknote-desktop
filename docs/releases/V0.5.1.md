## 中文更新说明

- 应用主标题与窗口标题统一为 `Worknote`。
- 新增完整的中文/英文界面切换，并记住上次选择；托盘菜单、按钮、日期、任务状态、提示和无障碍文案同步切换。
- 顶部区域改为紧凑布局：未完成、已完成和新增位于同一行；已有任务时默认收起快速记录，点击新增后展开。
- 顶部工作区从第一次滚动开始保持固定，不再先移动一小段；长任务列表浏览时仍可随时看到日期、统计和新增入口。
- `中 / EN` 切换按钮移动到窗口模式按钮下方，避免英文状态挤压标题。
- 普通窗口与贴边小窗采用更直观的完整文案；“切换到贴边小窗”作为主要操作突出显示。
- 未完成与已完成标签增大并加粗，任务创建日期保持清晰可读。
- README 增加 macOS 正确安装步骤与未公证版本的安全提示。
- 公开构建增加编译路径重映射，避免安装包包含构建机用户目录或本机绝对路径。
- GitHub Actions 普通检查任务使用只读权限，仅版本标签发行任务获得 Release 写权限。
- 新增长期“上传发布检查清单”，覆盖隐私洁净、代码审核、macOS/Windows 构建、签名状态、更新说明、哈希和发布后验证。

## English release notes

- Unified the main heading and native window title as `Worknote`.
- Added a complete, persistent Chinese/English interface switch, including tray items, controls, dates, task states, messages, and accessibility labels.
- Introduced a compact header with To do, Done, and Add on one row. Quick entry stays collapsed when tasks already exist and expands on demand.
- Kept the entire top workspace stationary from the first scroll movement, so the date, counts, and Add action remain available in long lists.
- Moved the `中 / EN` switch below the window-mode control to protect the English title from crowding.
- Replaced short window-mode labels with clearer full descriptions and emphasized the action that enters the side window.
- Increased the size and weight of the To do and Done labels while keeping task timestamps easy to read.
- Added accurate macOS installation and unsigned/notarization guidance to the README.
- Added release-build path remapping so packages do not expose the build machine's user directory or local absolute paths.
- Reduced GitHub Actions permissions: normal checks are read-only, and only tagged release builds can write Release assets.
- Added a reusable release checklist for privacy review, code checks, macOS/Windows packages, signing status, release notes, checksums, and post-release verification.

## Compatibility and data / 兼容性与数据

- The application identifier, SQLite database name, and operating-system application-data location remain unchanged.
- Existing tasks remain compatible; the update does not delete, reset, or upload user data.
- The selected language is stored locally on the device.

## Pre-release verification / 发布前验证

- JavaScript syntax: passed.
- Rust formatting: passed.
- Strict Clippy: passed with zero warnings.
- Rust tests: 5 passed, 0 failed.
- 480-pixel normal window, 360-pixel side window, bilingual switching, and sticky scrolling: passed.
- macOS and Windows release packages are built by GitHub Actions from the tagged public commit.
- Public package scans cover high-confidence secrets, forbidden data files, and build-machine absolute paths.

## Signing and known limitations / 签名与已知限制

- The public macOS package is not signed with an Apple Developer ID and is not notarized. Gatekeeper may require the documented “Open Anyway” step.
- The Windows installer is not signed with a commercial code-signing certificate and may display a SmartScreen warning.
